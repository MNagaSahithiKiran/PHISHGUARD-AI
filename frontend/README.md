# PhishGuard AI - Frontend SOC Dashboard

A modern Security Operations Center (SOC) dashboard engineered with React 18, TypeScript, Vite, and Tailwind CSS.

## Features

- **Dark SOC Aesthetic**: Professional cybersecurity UI with subtle glassmorphic panels, glowing status tokens, and clear contrast.
- **8 Dedicated Cyber Views**:
  - `Dashboard`: Live metrics connected to backend API, recent scans, threat and risk distributions.
  - `Website Scanner`: Immediate URL intake with SSRF barrier test presets and input sanitization.
  - `Scan Result`: Full scan inspection breakdown with 14+ lexical features and heuristic indicators.
  - `Scan History`: Filterable audit trail of all historical scans.
  - `Threat Intelligence`: Heuristic rules catalog and global threat feed connectors.
  - `Analytics`: Recharts visualization of real database records.
  - `About & IEEE Spec`: Academic problem formulation, research blueprint, and capstone documentation.
  - `Settings`: API connection configuration and defensive ingestion controls.
- **Zero Fake AI Metrics**: Empty states are clearly displayed when no records exist. No hardcoded or fabricated accuracy metrics.

## Running Locally

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Production build
npm run build
```
